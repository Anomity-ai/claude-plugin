# Security policy

This repository holds the Anomity plugin for Claude: Markdown skills and one
reference to the Anomity connector at `https://app.anomity.ai/mcp`. The plugin
runs no code on your machine.

## Report a vulnerability

Please report a suspected vulnerability privately, never in a public channel:

- **On GitHub:** open this repository's **Security** tab and select **Report a
  vulnerability**.
- **By email:** write to [support@anomity.ai](mailto:support@anomity.ai) with
  "Security" in the subject line.

Tell us what you found, how to reproduce it, and what an attacker could do with
it. We acknowledge every report and keep you informed until it is resolved.

## In scope

- The skills and the connector entry in this repository, including any
  instruction that could lead Claude to act on data it shouldn't trust.
- The Anomity connector and console at `app.anomity.ai`, which the plugin
  depends on.

## Supported versions

Only the latest published version of the plugin receives fixes. The directory
serves each newly published version to everyone who has the plugin installed.
